Enable and configure a carrier with the specified device options

Usage:
  arduino-linux-config carrier enable <carrier-name> [device=option...] [flags]

Examples:
  # To configure a media-carrier with two cameras attached, one type1:
  arduino-linux-config carrier enable media-carrier camera0=type1-2lanes camera1=type1-4lanes

Flags:
  -h, --help   help for enable

Global Flags:
      --format string      Output format (text, json) (default "text")
