A CLI to manage Arduino Linux Configurations

Usage:
  arduino-linux-config [command]

Available Commands:
  carrier     Manage Arduino Carriers
  completion  Generate the autocompletion script for the specified shell
  help        Help about any command
  version     

Flags:
      --format string      Output format (text, json) (default "text")
  -h, --help               help for arduino-linux-config
      --log-level string   Set the log level (debug, info, warn, error) (default "error")

Use "arduino-linux-config [command] --help" for more information about a command.
Manage Arduino Carriers, including listing, configuring, and resetting.

Usage:
  arduino-linux-config carrier [command]

Available Commands:
  disable     Disable a carrier and restore the base DTB
  enable      Enable and configure a carrier with the specified device options
  list        Lists the available carriers and devices for the current hardware
  show        Show the current configuration

Flags:
  -h, --help   help for carrier

Global Flags:
      --format string      Output format (text, json) (default "text")
      --log-level string   Set the log level (debug, info, warn, error) (default "error")

Use "arduino-linux-config carrier [command] --help" for more information about a command.
